# Asset sources

- Lamb, dog, meadow, rocks, bushes, flowers, butterflies, and UI icons: original procedural Canvas/SVG illustrations created for this game, source in `src/art.ts` and `src/main.ts`.
- Sound effects: original Web Audio oscillator synthesis in `src/audio.ts`.
- DM Sans and Fraunces: Google Fonts, distributed under the SIL Open Font License. Local font binaries are in `public/fonts`; licenses are stored alongside this file.
  - https://github.com/google/fonts/tree/main/ofl/dmsans
  - https://github.com/google/fonts/tree/main/ofl/fraunces
